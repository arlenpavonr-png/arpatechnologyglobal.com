# arpatechnologyglobal.com

Sitio de marketing en GitHub Pages con dominio personalizado (`CNAME`).

## Archivo que sirve la web pública

| URL pública | Archivo en este repo | Función |
|-------------|----------------------|---------|
| **https://arpatechnologyglobal.com/** | **`index.html`** | Landing de marketing (hero, módulos, perfiles, **precios `#precio`**, WhatsApp **573151831998**) |
| https://arpatechnologyglobal.com/app/ | `app/index.html` | Redirección a la PWA ARPA Suite en GitHub Pages |

**Nombre exacto del archivo publicado en la raíz del dominio: `index.html`**

No existe `landing.html` en este repositorio. GitHub Pages sirve `index.html` automáticamente en `/`.

## Dónde editar qué

- **Landing / precios / WhatsApp del sitio público** → editar **`index.html` aquí** y hacer push a `main`.
- **App ARPA Suite (PWA)** → repositorio `Formato-Arlenpav`, archivo `index.html` (URL: `https://arlenpavonr-png.github.io/Formato-Arlenpav/`).

## Despliegue

Push a la rama `main` de este repo. GitHub Pages publica la carpeta raíz en unos minutos.
